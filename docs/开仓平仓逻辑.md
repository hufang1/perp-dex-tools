## 系统概述

价差套利机器人在两个交易所（Extended和Lighter）之间进行套利交易：

- **Extended交易所**: 主要交易场所，使用挂单（maker）或吃单（taker）交易
- **Lighter交易所**: 对冲交易所，使用市价单对冲

**核心原则**:
- 使用对手价（bid/ask）而非中间价计算真实价差
- 强制使用taker订单确保成交
- 开仓后立即在Lighter对冲
- 五级优先级系统智能决策平仓时机

## 价差计算逻辑

### 1. 真实价差计算器 (RealSpreadCalculator)

**文件位置**: `spread/real_spread_calculator.py`

#### 核心概念

传统价差计算使用中间价（mid price），但中间价是"买不到也卖不出"的价格。真实价差计算使用对手价：

```python
# 做多价差 = Lighter卖出价（bid） - Extended买入价（ask）
spread_long = lighter_bid - extended_ask

# 做空价差 = Extended卖出价（bid） - Lighter买入价（ask）
spread_short = extended_bid - lighter_ask
```

#### 1.1 计算做多价差

```python
# 文件: spread/real_spread_calculator.py, 行53-139
def calculate_long_spread(
    self,
    extended_bid: Decimal,
    extended_ask: Decimal,
    lighter_bid: Decimal,
    lighter_ask: Decimal
) -> RealSpreadResult:
    """
    计算做多价差（Extended买，Lighter卖）

    算法:
        spread = lighter_bid - extended_ask
        spread_rate = spread / lighter_bid

    做多价差意味着：
    - 在Extended买入（支付ask价格）
    - 在Lighter卖出（获得bid价格）
    - 只有当lighter_bid > extended_ask时才盈利
    """
    # 行81-82: 计算真实价差（对手价）
    spread = lighter_bid - extended_ask

    # 行84-101: 计算价差率（如果lighter_bid无效则返回失败）
    if lighter_bid > 0:
        spread_rate = spread / lighter_bid
    else:
        return RealSpreadResult(is_valid=False, ...)

    # 行103-112: 计算点差成本
    extended_spread = extended_ask - extended_bid  # Extended点差
    lighter_spread = lighter_ask - lighter_bid    # Lighter点差

    # 做多成本分解：
    # - Extended买入成本点差 = (ask - bid) / 2 / lighter_bid
    # - Lighter卖出成本点差 = (ask - bid) / 2 / lighter_bid
    extended_cost = (extended_spread / 2) / lighter_bid
    lighter_cost = (lighter_spread / 2) / lighter_bid
    total_cost_rate = extended_cost + lighter_cost

    # 行121-124: 计算期望收益（扣除手续费和点差）
    taker_fees = self.config.extended_taker_fee_rate * 2  # 双边手续费
    expected_profit_rate = spread_rate - taker_fees - total_cost_rate

    # 行126: 判断是否有效（价差率为正）
    is_valid = spread_rate > 0

    # 行128-139: 返回结果对象
    return RealSpreadResult(
        is_valid=is_valid,
        direction='long_spread',
        spread=spread,
        spread_rate=spread_rate,
        extended_entry_price=extended_ask,   # 做多：Extended用ask买入
        lighter_entry_price=lighter_bid,    # 做多：Lighter用bid卖出
        extended_exit_price=extended_bid,   # 平仓：Extended用bid卖出
        lighter_exit_price=lighter_ask,    # 平仓：Lighter用ask买入
        costs=costs,
        expected_profit_rate=expected_profit_rate
    )
```

| 81 | `spread = lighter_bid - extended_ask` | 做多价差 = Lighter卖出价 - Extended买入价（都是对手价） |
| 85 | `spread_rate = spread / lighter_bid` | 价差率 = 价差 / Lighter价格（百分比） |

#### 1.3 自动选择最佳机会

```python
# 文件: spread/real_spread_calculator.py, 行228-295
def calculate_best_opportunity(
    self,
    extended_bid: Decimal,
    extended_ask: Decimal,
    lighter_bid: Decimal,
    lighter_ask: Decimal,
    min_spread_rate: Decimal
) -> RealSpreadResult:
    """
    计算最佳套利机会（自动选择做多或做空）
    """
    # 行249-251: 分别计算做多和做空价差
    long_result = self.calculate_long_spread(extended_bid, extended_ask, lighter_bid, lighter_ask)
    short_result = self.calculate_short_spread(extended_bid, extended_ask, lighter_bid, lighter_ask)

    # 行253-262: 选择价差率更大的方向
    if long_result.is_valid and short_result.is_valid:
        if long_result.spread_rate >= short_result.spread_rate:
            result = long_result  # 做多价差更大
        else:
            result = short_result  # 做空价差更大
    elif long_result.is_valid:
        result = long_result
    elif short_result.is_valid:
        result = short_result
    else:
        # 行264-277: 没有有效机会
        return RealSpreadResult(is_valid=False, ...)

    # 行279-293: 检查是否满足阈值
    if result.is_valid and result.expected_profit_rate < min_spread_rate:
        return RealSpreadResult(
            is_valid=False,
            failure_reason=f"期望收益率{result.expected_profit_rate:.4%}低于阈值{min_spread_rate:.4%}"
        )

    return result
```

| 行号 | 代码 | 解释 |
|------|------|------|
| 250 | `long_result = self.calculate_long_spread(...)` | 计算做多价差 |
| 251 | `short_result = self.calculate_short_spread(...)` | 计算做空价差 |
| 254-258 | `if long_result.spread_rate >= short_result.spread_rate` | 选择价差率更大的方向 |
| 280 | `if result.expected_profit_rate < min_spread_rate` | 检查是否超过最小阈值 |

### 2. 价差计算器集成 (SpreadCalculator)

**文件位置**: `spread/calculator.py`

```python
# 文件: spread/calculator.py, 行266-335
def calculate_real_spread_opportunity(
    self,
    extended_bid: Decimal,
    extended_ask: Decimal,
    lighter_bid: Decimal,
    lighter_ask: Decimal,
    min_spread_rate: Optional[Decimal] = None
) -> Optional[Dict[str, Any]]:
    """
    使用对手价计算真实价差机会
    """
    # 行303-304: 使用配置的有效最小价差率（考虑延迟缓冲）
    if min_spread_rate is None:
        min_spread_rate = self.config.effective_min_spread

    # 行306-313: 调用真实价差计算器
    result = self.real_spread_calc.calculate_best_opportunity(
        extended_bid=extended_bid,
        extended_ask=extended_ask,
        lighter_bid=lighter_bid,
        lighter_ask=lighter_ask,
        min_spread_rate=min_spread_rate
    )

    # 行315-316: 如果没有有效机会，返回None
    if not result.is_valid:
        return None

    # 行317-335: 构造机会字典
    quantity = self.config.order_quantity_usdt / result.extended_entry_price

    opportunity_type = (
        'buy_extended_sell_lighter' if result.direction == 'long_spread'
        else 'sell_extended_buy_lighter'
    )

    return {
        'spread': result.spread,                        # 真实价差
        'spread_rate': result.spread_rate,              # 价差率
        'direction': result.direction,                  # 'long_spread' | 'short_spread'
        'side': 'buy' if result.direction == 'long_spread' else 'sell',  # Extended方向
        'extended_side': 'buy' if result.direction == 'long_spread' else 'sell',
        'type': opportunity_type,
        'extended_price': result.extended_entry_price,  # Extended开仓价（对手价）
        'lighter_price': result.lighter_entry_price,    # Lighter开仓价（对手价）
        'expected_profit_rate': result.expected_profit_rate,
        'quantity': quantity,
        'real_spread': True,                            # 标记为真实价差
        'costs': result.costs                           # 成本分解
    }
```

```python
async def _strategy_loop(self):
    """主策略循环：持续监控价差并执行交易"""
    while not self.stop_flag:
        try:
            # 行277-280: 预热期检查（防止启动时立即开仓）
            if time.time() - self.startup_time < self.startup_warmup_seconds:
                await asyncio.sleep(0.5)
                continue

            # 行282-290: 获取最佳价格（订单簿最优报价）
            extended_bid = max(self.extended_orderbook['bids'].keys()) if self.extended_orderbook['bids'] else Decimal('0')
            extended_ask = min(self.extended_orderbook['asks'].keys()) if self.extended_orderbook['asks'] else Decimal('999999')
            lighter_bid = max(self.lighter_orderbook['bids'].keys()) if self.lighter_orderbook['bids'] else Decimal('0')
            lighter_ask = min(self.lighter_orderbook['asks'].keys()) if self.lighter_orderbook['asks'] else Decimal('999999')

            # 行291-294: 检查价格有效性
            if extended_bid <= 0 or lighter_bid <= 0:
                await asyncio.sleep(0.1)
                continue

            # 行296-303: 计算价差机会（使用真实价差计算）
            opportunity = self.calculator.calculate_real_spread_opportunity(
                extended_bid=extended_bid,
                extended_ask=extended_ask,
                lighter_bid=lighter_bid,
                lighter_ask=lighter_ask
            )

            # 行305-310: 如果发现机会
            if opportunity:
                self.stats['total_opportunities'] += 1

                # 只关注开新仓，平仓由 _monitor_pairs 处理

                # 行311-312: 检查是否可以开新仓
                if len(self.open_pairs) < self.config.max_open_pairs:
                    # 行313-319: 检查Lighter深度
                    hedge_side = 'sell' if opportunity['side'] == 'buy' else 'buy'
                    is_sufficient, safe_qty, avg_price = self.calculator.calculate_max_safe_quantity(
                        self.lighter_orderbook,
                        hedge_side,
                        opportunity['quantity']
                    )

                    if is_sufficient:
                        # 行322-326: 使用动态阈值
                        if self.adaptive_threshold_manager:
                            threshold = self.adaptive_threshold_manager.get_effective_min_spread_rate()
                        else:
                            threshold = self.config.effective_min_spread

                        # 行328-339: DEBUG日志记录真实价差
                        self.logger.debug(
                            f"📊 [真实价差详情] direction={opportunity.get('direction', 'N/A')}, "
                            f"extended_price={opportunity['extended_price']:.4f}, "
                            f"lighter_price={opportunity['lighter_price']:.4f}, "
                            f"spread={opportunity.get('spread', 0):.4f}, "
                            f"spread_rate={opportunity['spread_rate']:.4%}, "
                            f"expected_profit={opportunity['expected_profit_rate']:.4%}, "
                            f"【阈值对比】 spread_rate={opportunity['spread_rate']:.4%} >= "
                            f"threshold={threshold:.4%} ✓"
                        )

                        # 行340-346: 记录成本分解
                        if opportunity.get('costs'):
                            costs = opportunity['costs']
                            self.logger.debug(
                                f"📊 [成本分解] extended_cost={costs.extended_cost:.4%}, "
                                f"lighter_cost={costs.lighter_cost:.4%}, "
                                f"total_cost_rate={costs.total_cost_rate:.4%}"
                            )

                        # 行348-353: INFO日志记录发现机会
                        self.logger.info(
                            f"🎯 发现开仓机会: {opportunity['type']} "
                            f"价差率: {opportunity['spread_rate']:.4%} "
                            f"预期利润: {opportunity['expected_profit_rate']:.4%} "
                            f"(阈值: {threshold:.4%})"
                        )

                        # 行355-363: 检查是否正在开仓（防止并发）
                        if self.is_opening:
                            self.logger.warning(
                                f"⚠️ 正在执行开仓操作，跳过此机会 "
                                f"(防止Ext和Lighter仓位不对等)"
                            )
                            self.stats['opportunities_rejected'] += 1
                            await asyncio.sleep(0.5)
                            continue

                        # 行365-376: 使用锁确保同时只有一个开仓操作
                        async with self.opening_lock:
                            if self.is_opening:
                                self.logger.warning("⚠️ 开仓锁已获取，跳过")
                                continue

                            self.is_opening = True
                            try:
                                await self._open_new_pair(opportunity)
                            finally:
                                self.is_opening = False

                    # 行377-382: Lighter深度不足
                    else:
                        self.stats['opportunities_rejected'] += 1
                        self.logger.debug(
                            f"⚠️ Lighter 深度不足: "
                            f"{safe_qty:.4f} < {opportunity['quantity']:.4f}"
                        )

                # 行383-387: 已达最大套利对数
                else:
                    self.stats['opportunities_rejected'] += 1
                    self.logger.debug(
                        f"⚠️ 已达最大套利对数: {len(self.open_pairs)}/{self.config.max_open_pairs}"
                    )

            # 行388-395: 没有有效机会
            else:
                self.stats['threshold_rejections'] += 1
                threshold = self.config.effective_min_spread
                self.logger.debug(
                    f"📊 [阈值检查] 无有效机会，当前价差不满足阈值 {threshold:.4%}"
                )

            # 行397: 100ms检查间隔
            await asyncio.sleep(0.1)

        # 行399-402: 异常处理
        except Exception as e:
            self.logger.error(f"策略循环错误: {e}")
            self.logger.error(traceback.format_exc())
            await asyncio.sleep(1)
```

```python
        extended_ask = min(self.extended_orderbook['asks'].keys()) if self.extended_orderbook['asks'] else Decimal('999999')
        lighter_bid = max(self.lighter_orderbook['bids'].keys()) if self.lighter_orderbook['bids'] else Decimal('0')
        lighter_ask = min(self.lighter_orderbook['asks'].keys()) if self.lighter_orderbook['asks'] else Decimal('999999')

        # ========== 预检查：Lighter对冲条件 ==========
        # 行873-876: 确定对冲方向
        hedge_side = 'sell' if opportunity['side'] == 'buy' else 'buy'
        self.logger.info(f"[预检查] 检查Lighter对冲条件...")

        # 行878-882: 检查Lighter订单簿深度（USDT价值）
        lighter_depth_value = self.calculator.check_lighter_depth_value(
            lighter_orderbook=self.lighter_orderbook,
            side=hedge_side
        )

        # 行884-890: 深度不足时拒绝
        if lighter_depth_value < self.config.min_lighter_depth_usdt:
            self.logger.warning(
                f"❌ 预检查失败: Lighter深度不足 "
                f"(${lighter_depth_value:.2f} < ${self.config.min_lighter_depth_usdt})"
            )
            self.stats['opportunities_rejected'] += 1
            return False

        # 行892-905: 检查具体的安全数量
        is_sufficient, safe_quantity, avg_price = self.calculator.calculate_max_safe_quantity(
            lighter_orderbook=self.lighter_orderbook,
            side=hedge_side,
            target_quantity=opportunity['quantity']
        )

        if not is_sufficient:
            self.logger.warning(
                f"❌ 预检查失败: Lighter深度不足以执行完整对冲 "
                f"(需要{opportunity['quantity']:.4f}, 安全{safe_quantity:.4f})"
            )
            self.stats['opportunities_rejected'] += 1
            return False

        # 行907-910: 预检查通过
        self.logger.info(
            f"✅ 预检查通过: Lighter深度=${lighter_depth_value:.2f}, "
            f"可对冲{safe_quantity:.4f} @ ${avg_price:.2f}"
        )

        # ========== 001-fix-order-type: 强制使用Taker订单 ==========
        # 行912-923: 强制使用taker订单，使用对手价
        use_maker = False  # 强制使用taker订单

        # 使用对手价作为taker订单价格
        if opportunity['side'] == 'buy':
            extended_price = extended_ask  # 买单使用ask价格（对手价）
        else:
            extended_price = extended_bid  # 卖单使用bid价格（对手价）

        self.logger.info(f"[001-fix-order-type] 使用Taker订单: side={opportunity['side']}, price=${extended_price:.4f}")

        # ========== 步骤1: Extended下单 ==========
        # 行925-931: Extended下单（强制post_only=False使用taker）
        order = await self.order_manager.place_spread_maker_order(
            side=opportunity['side'],
            price=extended_price,
            quantity=opportunity['quantity'],
            post_only=False  # 001-fix-order-type: 强制taker订单
        )

        self.logger.info(f"[DEBUG] 下单返回: success={order['success']}, order_id={order.get('order_id')}")

        # 行935-938: 下单失败处理
        if not order['success']:
            self.stats['failed_opens'] += 1
            self.consecutive_failures += 1
            return False

        # ========== 步骤2: 等待成交 ==========
        # 行942-948: taker订单直接等待成交
        fill_result = await self.order_manager.wait_for_fill(
            order_id=order['order_id'],
            timeout=self.config.extended_fill_timeout,
            allow_partial=self.config.enable_partial_fill
        )

        # 行950-955: 完全未成交处理
        if fill_result['status'] == 'TIMEOUT' and fill_result['filled_quantity'] == 0:
            await self.order_manager.cancel_order(order['order_id'])
            self.stats['failed_opens'] += 1
            self.consecutive_failures += 1
            return False

        # 行957-960: 部分成交或成交数量为0处理
        if fill_result['filled_quantity'] == 0:
            self.stats['failed_opens'] += 1
            self.consecutive_failures += 1
            return False

        # ========== 步骤3: 执行对冲 ==========
        # 行962-968: 在Lighter对冲
        hedge_side = 'sell' if opportunity['side'] == 'buy' else 'buy'
        hedge_result = await self.hedge_manager.execute_hedge(
            side=hedge_side,
            quantity=fill_result['filled_quantity'],
            expected_price=opportunity['lighter_price']
        )

        # 行970-974: 记录对冲尝试结果到安全监控器
        await self.safety_monitor.record_hedge_attempt(
            success=hedge_result['success'],
            failure_reason=hedge_result.get('error')
        )

        # 行976-977: 保留旧的对冲记录方法
        self._record_hedge_attempt(hedge_result['success'])

        # ========== 对冲失败处理 ==========
        # 行979-1034: 对冲失败时的处理
        if not hedge_result['success']:
            self.stats['failed_opens'] += 1
            self.consecutive_failures += 1

            # 行983-994: 记录未对冲的Extended仓位
            unhedged_position = {
                'pair_id': self.next_pair_id,
                'order_id': order['order_id'],
                'side': opportunity['side'],
                'quantity': fill_result['filled_quantity'],
                'price': fill_result['filled_price'],
                'expected_price': opportunity['lighter_price'],
                'timestamp': time.time(),
                'error': hedge_result.get('error', 'Unknown')
            }
            self.unhedged_positions.append(unhedged_position)

            # 行996-998: 记录到交易日志
            if not self.trade_logger.log_unhedged_position(unhedged_position):
                self.logger.warning(f"交易日志记录失败 (未对冲仓位)，但交易继续")

            # 行1000-1007: 错误日志
            self.logger.error(
                f"❌ 对冲失败! Extended单边仓位累积!\n"
                f"   订单ID: {order['order_id']}\n"
                f"   方向: {opportunity['side']}\n"
                f"   数量: {fill_result['filled_quantity']:.4f} @ {fill_result['filled_price']:.2f}\n"
                f"   错误: {hedge_result.get('error', 'Unknown')}\n"
                f"   未对冲仓位总数: {len(self.unhedged_positions)}"
            )

            # 行1009-1024: 001-fix-order-type: 记录对冲失败
            error_msg = hedge_result.get('error', 'Unknown')
            failure_reason = FailureReason.NETWORK_TIMEOUT
            if 'insufficient' in error_msg.lower() or 'balance' in error_msg.lower():
                failure_reason = FailureReason.INSUFFICIENT_BALANCE
            elif 'rejected' in error_msg.lower():
                failure_reason = FailureReason.ORDER_REJECTED

            self.success_tracker.record_operation(SpreadOperationResult(
                timestamp=time.time(),
                operation_type=OperationType.OPEN_FAILED,
                status=OperationStatus.FAILED,
                exchange=ExchangeType.LIGHTER,
                failure_reason=failure_reason,
                error_message=error_msg
            ))

            # 行1026-1033: 触发紧急熔断
            self.is_paused = True
            self.pause_until = time.time() + 3600  # 暂停1小时
            self.logger.error(
                f"🚨 触发紧急熔断! 检测到未对冲仓位，暂停交易1小时!\n"
                f"   请手动检查并平仓未对冲的Extended仓位!"
            )

            return False

        # ========== 步骤4: 创建套利对 ==========
        # 行1036-1046: 创建SpreadPair对象
        pair = SpreadPair(
            pair_id=self.next_pair_id,
            extended_side=opportunity['side'],
            extended_price=fill_result['filled_price'],
            extended_quantity=fill_result['filled_quantity'],
            lighter_price=hedge_result['filled_price'],
            lighter_quantity=hedge_result['filled_quantity'],
            extended_order_id=order['order_id'],
            lighter_order_id=hedge_result.get('order_id')
        )

        # ========== 001-fix-order-type: 验证仓位一致性 ==========
        # 行1048-1067: 验证开仓后仓位一致性
        if self.config.enable_position_consistency_check:
            check_result = await self.validate_position_consistency(pair)

            if not check_result.is_consistent:
                self.logger.warning(
                    f"[001-fix-order-type] 开仓后仓位不一致！\n"
                    f"   套利对ID: {pair.pair_id}\n"
                    f"   Extended: {pair.extended_quantity:.4f} @ ${pair.extended_price:.2f}\n"
                    f"   Lighter: {pair.lighter_quantity:.4f} @ ${pair.lighter_price:.2f}\n"
                    f"   差异: {check_result.difference:.4f} ({check_result.difference_rate:.2%})\n"
                    f"   阈值: 数量<{self.config.position_consistency_threshold}, "
                    f"比率<{self.config.position_consistency_rate_threshold:.0%}"
                )

        # 行1068-1074: 更新统计
        self.next_pair_id += 1
        self.open_pairs.append(pair)
        self.stats['successful_opens'] += 1
        self.stats['opportunities_taken'] += 1
        self.stats['max_open_pairs'] = max(self.stats['max_open_pairs'], len(self.open_pairs))
        self.consecutive_failures = 0

        # ========== 001-fix-order-type: 记录开仓成功 ==========
        # 行1077-1088: 记录OPEN_SUCCESS
        self.success_tracker.record_operation(SpreadOperationResult(
            timestamp=time.time(),
            operation_type=OperationType.OPEN_SUCCESS,
            status=OperationStatus.SUCCESS,
            exchange=ExchangeType.BOTH,
            order_id=pair.open_extended_order_id,
            quantity=pair.extended_quantity,
            price=pair.extended_price,
            pair_id=pair.pair_id,
            spread_rate=pair.open_spread_rate
        ))

        # 行1090-1099: 增强开仓日志
        self.logger.info(
            f"✅ 开仓成功! 套利对 #{pair.pair_id}\n"
            f"   方向: {pair.extended_side.upper()}\n"
            f"   数量: {pair.extended_quantity:.4f}\n"
            f"   Extended: 价格@${pair.extended_price:.2f} (订单ID: {pair.open_extended_order_id})\n"
            f"   Lighter: 价格@${pair.lighter_price:.2f} (订单ID: {pair.open_lighter_order_id})\n"
            f"   开仓价差: ${pair.open_spread:.2f} ({pair.open_spread_rate:.4%})\n"
            f"   时间戳: {pair.open_time:.2f}"
        )

        # ========== 记录到交易日志 ==========
        # 行1101-1103: 记录开仓交易
        if not self.trade_logger.log_opening_trade(pair):
            self.logger.warning(f"交易日志记录失败 (开仓) - 套利对 #{pair.pair_id}，但交易继续")

        # ========== 记录价差快照 ==========
        # 行1105-1119: 记录开仓时的价差快照
        spread_snapshot = SpreadSnapshot(
            timestamp=time.time(),
            extended_bid=extended_bid,
            extended_ask=extended_ask,
            extended_mid=(extended_bid + extended_ask) / Decimal('2'),
            lighter_bid=lighter_bid,
            lighter_ask=lighter_ask,
            lighter_mid=(lighter_bid + lighter_ask) / Decimal('2'),
            spread=pair.open_spread,
            spread_rate=pair.open_spread_rate,
            spread_sign="positive" if pair.open_spread > 0 else "negative" if pair.open_spread < 0 else "zero",
            arbitrage_direction="long_spread" if pair.extended_side == 'buy' else "short_spread"
        )
        if not self.trade_logger.log_spread_snapshot(spread_snapshot):
            self.logger.warning(f"交易日志记录失败 (价差快照) - 套利对 #{pair.pair_id}，但交易继续")

        return True

    except Exception as e:
        self.logger.error(f"开仓异常: {e}")
        self.logger.error(traceback.format_exc())
        return False
```

```python
# 文件: spread/bot.py, 行617-776
def _check_close_conditions(
    self,
    pair: SpreadPair,
    extended_bid: Decimal,
    extended_ask: Decimal,
    lighter_bid: Decimal,
    lighter_ask: Decimal
) -> Optional[CloseDecision]:
    """
    检查平仓条件（五级优先级）

    按优先级检查是否应该平仓：
    P1: 盈利目标平仓 - 未实现盈亏达到目标收益率
    P2: 时间小额平仓 - 持仓超时且有小额利润
    P3: 回本止损 - 持仓超时且亏损，等待回本后平仓
    P4: 强制平仓 - 持仓超过最大时间
    P5: 价差扩大延迟平仓 - 价差扩大时的延迟处理
    """
    # 行645-648: 检查价差收敛
    is_converged, status_msg, spread_change = pair.is_spread_converged(
        extended_bid, extended_ask, lighter_bid, lighter_ask
    )

    # 行650-656: 确定平仓价格（根据持仓方向选择对手价）
    if pair.extended_side == 'buy':
        close_extended_price = extended_bid   # 做多平仓：卖出用bid
        close_lighter_price = lighter_ask    # 做多平仓：买入用ask
    else:
        close_extended_price = extended_ask  # 做空平仓：买入用ask
        close_lighter_price = lighter_bid   # 做空平仓：卖出用bid

    # 行658-665: 计算未实现盈亏
    unrealized_pnl = pair.calculate_unrealized_pnl(
        close_extended_price, close_lighter_price
    )
    investment = pair.extended_quantity * pair.extended_price
    pnl_rate = unrealized_pnl / investment if investment > 0 else Decimal('0')

    # 行667-668: 持仓时间
    holding_time = pair.holding_time

    # ===== Priority 1: 盈利目标平仓 =====
    # 行670-687: P1 - 盈利目标达标
    if self.config.enable_profit_target:
        profit_target = investment * self.config.profit_target_rate
        if unrealized_pnl >= profit_target:
            return self._create_close_decision(
                pair=pair,
                should_close=True,
                priority=1,
                reason=f"盈利目标达标 (PnL=${unrealized_pnl:.2f} >= ${profit_target:.2f})",
                reason_code="P1_CONVERGE_PROFIT",
                spread_change=spread_change,
                unrealized_pnl=unrealized_pnl,
                pnl_rate=pnl_rate,
                holding_time=holding_time,
                extended_close_price=close_extended_price,
                lighter_close_price=close_lighter_price,
                is_warning=False
            )

    # ===== Priority 2: 时间小额平仓 =====
    # 行689-705: P2 - 持仓超时且有利润
    if holding_time > self.config.time_close_threshold:
        if unrealized_pnl > 0:
            return self._create_close_decision(
                pair=pair,
                should_close=True,
                priority=2,
                reason=f"时间小额平仓 (持仓{holding_time:.0f}秒, PnL=${unrealized_pnl:.2f})",
                reason_code="P2_TIME_SMALL_PROFIT",
                spread_change=spread_change,
                unrealized_pnl=unrealized_pnl,
                pnl_rate=pnl_rate,
                holding_time=holding_time,
                extended_close_price=close_extended_price,
                lighter_close_price=close_lighter_price,
                is_warning=False
            )

    # ===== Priority 3: 回本止损 =====
    # 行707-730: P3 - 持仓超时且亏损，等待回本
    if holding_time > self.config.time_close_threshold:
        if unrealized_pnl < 0:
            # 检查是否接近回本
            if unrealized_pnl >= 0:
                return self._create_close_decision(
                    pair=pair,
                    should_close=True,
                    priority=3,
                    reason=f"回本止损 (持仓{holding_time:.0f}秒, PnL=${unrealized_pnl:.2f})",
                    reason_code="P3_BREAK_EVEN",
                    spread_change=spread_change,
                    unrealized_pnl=unrealized_pnl,
                    pnl_rate=pnl_rate,
                    holding_time=holding_time,
                    extended_close_price=close_extended_price,
                    lighter_close_price=close_lighter_price,
                    is_warning=False
                )
            # 否则继续等待
            self.logger.debug(
                f"套利对 #{pair.pair_id} 持仓{holding_time:.0f}秒, "
                f"PnL=${unrealized_pnl:.2f}, 等待回本"
            )

    # ===== Priority 4: 强制平仓 =====
    # 行732-747: P4 - 持仓超过最大时间
    if holding_time > self.config.max_holding_time:
        return self._create_close_decision(
            pair=pair,
            should_close=True,
            priority=4,
            reason=f"强制平仓 (持仓{holding_time:.0f}秒 > {self.config.max_holding_time}秒, PnL=${unrealized_pnl:.2f})",
            reason_code="P4_FORCE_CLOSE",
            spread_change=spread_change,
            unrealized_pnl=unrealized_pnl,
            pnl_rate=pnl_rate,
            holding_time=holding_time,
            extended_close_price=close_extended_price,
            lighter_close_price=close_lighter_price,
            is_warning=True
        )

    # ===== Priority 5: 价差扩大延迟平仓 =====
    # 行749-773: P5 - 价差扩大时的处理
    if not is_converged:
        if self.config.enable_delay_on_divergence:
            self.logger.debug(
                f"套利对 #{pair.pair_id} 价差扩大，延迟平仓: {status_msg}"
            )
            return None
        else:
            return self._create_close_decision(
                pair=pair,
                should_close=True,
                priority=5,
                reason=f"价差扩大平仓: {status_msg}",
                reason_code="P5_DIVERGENCE_CLOSE",
                spread_change=spread_change,
                unrealized_pnl=unrealized_pnl,
                pnl_rate=pnl_rate,
                holding_time=holding_time,
                extended_close_price=close_extended_price,
                lighter_close_price=close_lighter_price,
                is_warning=True
            )

    # 行775: 不满足任何平仓条件
    return None
```

### 平仓条件优先级表

| 优先级 | 条件 | 触发条件 | 说明 |
|--------|------|----------|------|
| P1 | 盈利目标 | `unrealized_pnl >= profit_target` | 达到目标收益率立即平仓 |
| P2 | 时间小额 | `holding_time > time_close_threshold AND unrealized_pnl > 0` | 持仓超时且有利润 |
| P3 | 回本止损 | `holding_time > time_close_threshold AND unrealized_pnl < 0 AND unrealized_pnl >= 0` | 亏损时等待回本 |
| P4 | 强制平仓 | `holding_time > max_holding_time` | 超过最大持仓时间强制平仓 |
| P5 | 价差扩大 | `not is_converged AND NOT enable_delay_on_divergence` | 价差扩大时根据配置决定 |

```python
# 文件: spread/bot.py, 行1522-1654+
async def _close_pair_with_market_price(
    self,
    pair: SpreadPair,
    extended_bid: Decimal,
    extended_ask: Decimal,
    lighter_bid: Decimal,
    lighter_ask: Decimal
) -> bool:
    """
    使用市价（对手价）平仓套利对

    根据持仓方向选择正确的对手价进行平仓：
    - 做多仓位（extended_side='buy'）:
      - Extended卖出平仓：使用bid价格
      - Lighter买入平仓：使用ask价格
    - 做空仓位（extended_side='sell'）:
      - Extended买入平仓：使用ask价格
      - Lighter卖出平仓：使用bid价格
    """
    try:
        self.logger.info(f"[市价平仓] 开始平仓套利对 #{pair.pair_id}")

        # ========== 001-fix-order-type: 记录平仓尝试 ==========
        # 行1561-1568: 记录CLOSE_ATTEMPT
        self.success_tracker.record_operation(SpreadOperationResult(
            timestamp=time.time(),
            operation_type=OperationType.CLOSE_ATTEMPT,
            status=OperationStatus.PENDING,
            exchange=ExchangeType.BOTH,
            pair_id=pair.pair_id
        ))

        # ========== 步骤1: 防止重复平仓 ==========
        # 行1570-1576: 检查is_closing标志
        if getattr(pair, 'is_closing', False):
            self.logger.warning(f"套利对 #{pair.pair_id} 正在平仓中，跳过")
            return False

        pair.is_closing = True

        # ========== 步骤2: 确定平仓价格 ==========
        # 行1578-1594: 根据持仓方向选择对手价
        if pair.extended_side == 'buy':
            # 做多平仓：卖出Extended（对手价bid），买入Lighter（对手价ask）
            close_extended_price = extended_bid
            close_lighter_price = lighter_ask
        else:
            # 做空平仓：买入Extended（对手价ask），卖出Lighter（对手价bid）
            close_extended_price = extended_ask
            close_lighter_price = lighter_bid

        self.logger.debug(
            f"平仓价格选择: {pair.extended_side}仓位\n"
            f"  Extended平仓价格: ${close_extended_price:.2f} "
            f"({'bid' if pair.extended_side == 'buy' else 'ask'})\n"
            f"  Lighter平仓价格: ${close_lighter_price:.2f} "
            f"({'ask' if pair.extended_side == 'buy' else 'bid'})"
        )

        # ========== 步骤3: 构造opportunity字典 ==========
        # 行1596-1601: 复用_close_pair的接口
        opportunity = {
            'side': 'sell' if pair.extended_side == 'buy' else 'buy',
            'extended_price': close_extended_price,
            'lighter_price': close_lighter_price
        }

        # ========== 步骤4: 调用平仓逻辑 ==========
        # 行1603-1604: 执行平仓
        success = await self._close_pair(pair, opportunity)

        # ========== 步骤5: 失败处理 ==========
        # 行1606-1621: 平仓失败处理
        if not success:
            self.logger.error(f"市价平仓失败！套利对 #{pair.pair_id} 仍持仓")
            pair.is_closing = False  # 重置标志，允许重试

            # 001-fix-order-type: 记录平仓失败
            self.success_tracker.record_operation(SpreadOperationResult(
                timestamp=time.time(),
                operation_type=OperationType.CLOSE_FAILED,
                status=OperationStatus.FAILED,
                exchange=ExchangeType.BOTH,
                pair_id=pair.pair_id,
                failure_reason=FailureReason.UNKNOWN_ERROR,
                error_message="市价平仓失败"
            ))

            return False

        # ========== 步骤6: 记录平仓成功 ==========
        # 行1623-1631: 001-fix-order-type: 记录CLOSE_SUCCESS
        self.success_tracker.record_operation(SpreadOperationResult(
            timestamp=time.time(),
            operation_type=OperationType.CLOSE_SUCCESS,
            status=OperationStatus.SUCCESS,
            exchange=ExchangeType.BOTH,
            pair_id=pair.pair_id,
            price=close_extended_price
        ))

        # ========== 步骤7: 记录平仓分析 ==========
        # 行1633-1654: 创建平仓分析对象并记录
        is_converged, status_msg, spread_change = pair.is_spread_converged(
            extended_bid, extended_ask, lighter_bid, lighter_ask
        )

        decision = CloseDecision(
            pair_id=pair.pair_id,
            should_close=True,
            priority=4,
            reason="市价强制平仓",
            reason_code="MARKET_FORCE_CLOSE",
            spread_change=spread_change,
            unrealized_pnl=pair.realized_pnl if pair.realized_pnl else Decimal('0'),
            pnl_rate=Decimal('0'),
            holding_time=pair.holding_time,
            is_warning=True,
            timestamp=time.time(),
            extended_close_price=close_extended_price,
            lighter_close_price=close_lighter_price
        )

        # 记录平仓分析
        if not self.trade_logger.log_close_analysis(decision):
            self.logger.warning(f"交易日志记录失败 (平仓分析) - 套利对 #{pair.pair_id}，但交易继续")

        return True

    except Exception as e:
        self.logger.error(f"平仓异常: {e}")
        self.logger.error(traceback.format_exc())
        return False
```

## 价差收敛检查

**文件位置**: `spread/spread_pair.py`

```python
# 文件: spread/spread_pair.py, 行248-318
def is_spread_converged(
    self,
    extended_bid: Decimal,
    extended_ask: Decimal,
    lighter_bid: Decimal,
    lighter_ask: Decimal
) -> Tuple[bool, str, SpreadChange]:
    """
    检查价差是否收敛

    算法:
    1. 计算当前中间价差
    2. 计算价差变化 = current_spread - open_spread
    3. 根据持仓方向判断收敛:
       - 做多: spread_delta > 0 → 收敛
       - 做空: spread_delta < 0 → 收敛
    """
    # 行274-277: 计算当前中间价差
    current_extended_mid = (extended_bid + extended_ask) / Decimal('2')
    current_lighter_mid = (lighter_bid + lighter_ask) / Decimal('2')
    current_spread = current_extended_mid - current_lighter_mid

    # 行279-280: 计算价差变化
    spread_delta = current_spread - self.open_spread

    # 行282-296: 根据持仓方向判断收敛
    if self.extended_side == 'buy':
        # 做多价差：期待价差变大（向正方向）
        is_converged = spread_delta > 0
        if spread_delta > 0:
            status = f"价差收敛: {self.open_spread:.2f} → {current_spread:.2f} (+{spread_delta:.2f})"
        else:
            status = f"价差扩大: {self.open_spread:.2f} → {current_spread:.2f} ({spread_delta:.2f})"
    else:
        # 做空价差：期待价差变小（向负方向）
        is_converged = spread_delta < 0
        if spread_delta < 0:
            status = f"价差收敛: {self.open_spread:.2f} → {current_spread:.2f} ({spread_delta:.2f})"
        else:
            status = f"价差扩大: {self.open_spread:.2f} → {current_spread:.2f} (+{spread_delta:.2f})"

    # 行298-302: 计算变化率
    if self.open_spread != 0:
        spread_change_rate = spread_delta / abs(self.open_spread)
    else:
        spread_change_rate = Decimal('0')

    # 行304-305: 判断当前是否有利
    is_favorable = is_converged

    # 行307-316: 创建SpreadChange对象
    spread_change = SpreadChange(
        open_spread=self.open_spread,
        current_spread=current_spread,
        spread_delta=spread_delta,
        spread_change_rate=spread_change_rate,
        is_converged=is_converged,
        is_favorable=is_favorable,
        status=status
    )

    return is_converged, status, spread_change
```

### 价差收敛判断表

| 持仓方向 | 收敛条件 | 有利条件 | 说明 |
|----------|----------|----------|------|
| 做多（buy） | `spread_delta > 0` | `is_converged = True` | 价差变大（向正方向）有利 |
| 做空（sell） | `spread_delta < 0` | `is_converged = True` | 价差变小（向负方向）有利 |

```python
def calculate_unrealized_pnl(
    self,
    current_extended_price: Decimal,
    current_lighter_price: Decimal
) -> Decimal:
    """
    计算未实现盈亏（浮动盈亏）

    Args:
        current_extended_price: 当前Extended价格（用于平仓的价格）
        current_lighter_price: 当前Lighter价格（用于平仓的价格）

    Returns:
        未实现盈亏（USDT）
    """
    if self.extended_side == 'buy':
        # 开仓: Extended买, Lighter卖
        # 平仓: Extended卖, Lighter买
        extended_pnl = (current_extended_price - self.extended_price) * self.extended_quantity
        lighter_pnl = (self.lighter_price - current_lighter_price) * self.lighter_quantity
    else:
        # 开仓: Extended卖, Lighter买
        # 平仓: Extended买, Lighter卖
        extended_pnl = (self.extended_price - current_extended_price) * self.extended_quantity
        lighter_pnl = (current_lighter_price - self.lighter_price) * self.lighter_quantity

    return extended_pnl + lighter_pnl
```

## 总结

### 开仓流程总结

1. **价差计算**: 使用真实价差（对手价）计算套利机会
2. **安全检查**: 检查安全监控器和熔断器状态
3. **预检查**: 验证Lighter深度是否足够对冲
4. **Extended下单**: 使用taker订单（post_only=False）和对手价
5. **等待成交**: 等待Extended订单成交
6. **执行对冲**: 在Lighter执行反向订单
7. **创建套利对**: 创建SpreadPair对象并验证仓位一致性
8. **记录成功**: 记录日志和价差快照

### 平仓流程总结

1. **监控循环**: 定期检查持仓状态
2. **价差收敛检查**: 计算当前价差与开仓价差的变化
3. **五级优先级判断**: 按P1-P5优先级决定是否平仓
4. **价格选择**: 根据持仓方向选择正确的对手价
5. **执行平仓**: 同时平仓Extended和Lighter
6. **记录结果**: 更新统计数据和日志

### 关键要点

1. **使用对手价**: 不使用中间价，确保计算的价差是可交易的
2. **强制taker订单**: 确保订单能够立即成交
3. **仓位一致性验证**: 开仓后验证两个交易所的仓位数量一致
4. **五级优先级系统**: 智能决策平仓时机，最大化收益
5. **安全监控**: 对冲失败时触发熔断，防止单边仓位累积
