## 🔑 核心设计亮点

### 1. **优先平仓机制**

```python
if 新机会是反方向 and 有持仓:
    # 优先平仓 (最佳获利时机)
    平仓现有套利对
else:
    # 检查是否可以开新仓
    if 当前套利对数 < max_open_pairs:
        开新的套利对
```

### 2. **三层止盈/止损**

| 优先级 | 触发条件 | 说明 |
|--------|---------|------|
| ⭐⭐⭐ | 价差反转 | 反向价差出现,最佳平仓时机 |
| ⭐⭐ | 时间止盈 | 持仓 > 30 分钟,防止长期持仓 |
| ⭐ | 盈利/止损 | 达到目标利润或止损线 |

### 3. **深度保护机制**

```python
# 下单量不超过 Lighter 深度的 50%
safe_quantity = lighter_depth * 0.5
quantity = min(order_quantity, safe_quantity)
```

### 4. **断路器保护**

```python
if consecutive_failures >= 3:
    暂停 60 秒
    清零失败计数
```

### 2. **风险提示**

⚠️ **对冲失败风险**: 这是最大风险!
- Extended 成交但 Lighter 对冲失败
- 会导致单边持仓,承担价格风险
- 建议设置紧急通知

⚠️ **网络延迟风险**:
- WebSocket 延迟
- 价格变化快于对冲速度
- 使用延迟缓冲预留安全边际

⚠️ **深度风险**:
- Lighter 深度不足
- 对冲滑点过大
- 严格遵守深度比例限制

### 3. **监控指标**

需要重点监控:
- ✅ 对冲成功率 (应 > 95%)
- ✅ 平均滑点 (应 < 0.1%)
- ✅ 套利对盈亏分布
- ✅ 持仓时间分布
