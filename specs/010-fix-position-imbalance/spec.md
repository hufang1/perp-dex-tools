## 问题分析

基于一夜运行的数据分析，发现了两个关键问题：

### 问题1：实际仓位严重失衡（Extended 0.21 ETH vs Lighter 0.02 ETH）

**现象**：
- 实际交易所仓位检查发现：Extended持仓0.21 ETH，Lighter持仓0.02 ETH
- 交易日志显示：差异率200.00%，状态为"严重失衡"
- **这是真实的仓位失衡，而非显示错误！**

**根本原因分析**：

1. **Lighter对冲订单大量失败**
   - Extended订单持续成交（累积0.21 ETH）
   - Lighter对冲订单大部分失败（仅成交0.02 ETH）
   - 导致约90%的仓位处于未对冲状态

2. **对冲失败未触发保护机制**
   - 系统没有正确检测到对冲失败
   - 没有及时停止开仓或强制平仓
   - 未对冲仓位持续累积

3. **仓位平衡计算存在显示问题**
   - 虽然有真实失衡，但差异率的计算方式也有问题
   - 当前计算：diff_qty = |extended - lighter| = |0.21 - 0.02| = 0.19
   - 差异率计算：diff_rate = 0.19 / 0.02 = 950%（或显示200%是因为多笔交易累积）

**正确的仓位平衡计算**：

对于对冲策略（符号相反，数量相等）：
```python
# 计算总暴露度（两个交易所的绝对值之和）
total_exposure = abs(extended_total) + abs(lighter_total)
# 计算实际差异（两个绝对值之间的差异）
diff_qty = abs(abs(extended_total) - abs(lighter_total))
# 计算差异率
diff_rate = diff_qty / total_exposure if total_exposure > 0 else 0
```

对于用户的实际情况（Extended 0.21, Lighter 0.02）：
- total_exposure = 0.21 + 0.02 = 0.23
- diff_qty = |0.21 - 0.02| = 0.19
- diff_rate = 0.19 / 0.23 = 82.6%（真实失衡率）

对于完全对冲的理想状态：
- total_exposure = 0.01 + 0.01 = 0.02
- diff_qty = |0.01 - 0.01| = 0
- diff_rate = 0%（正确）

### 问题2：开仓机会太少（10小时仅2次）

**数据分析**（基于2026-01-10和2026-01-11的价差CSV数据）：

| 统计项 | 2026-01-10 | 2026-01-11 |
|--------|------------|------------|
| 总样本数 | 6,908 | 1,935 |
| 做多价差率（中位数） | 0.0905% | 0.0825% |
| 做多价差率（75%分位） | 0.2055% | 0.1375% |
| 做多价差率（90%分位） | 0.2961% | 0.2217% |
| 平均总成本率 | 0.0024% | 0.0024% |

**当前配置**：
- min_spread_rate = 0.001（0.10%）
- effective_min_spread = 0.001 + 0.0001 = 0.0011（0.11%）
- profit_target_rate = 0.0005（0.05%）
- time_close_threshold = 60秒

**问题**：
- 当前0.11%的开仓阈值高于中位数，错过了大量机会
- 大部分价差机会在0.08%-0.20%之间，但系统只捕捉0.11%以上的机会
- 手续费成本很低（平均0.0024%），理论上可以在更低的价差下盈利

**优化方案**：
基于数据分析，建议调整阈值：
- 开仓阈值降至0.06%（接近中位数0.08%，留有安全边际）
- 平仓阈值降至0.03%（确保有正收益，低于0.06%开仓阈值）
- 盈利目标降至0.02%（接受微薄盈利）

- FR-010: 系统必须确保开仓阈值高于手续费成本率（当前约为0.0024%），保证正期望收益

- FR-013: 系统必须记录所有开平仓决策的价差数据和成本分解，便于后续分析

**P2 - 优化功能需求**：

- FR-014: 系统必须支持可配置的平仓阈值，默认值为0.03%（确保低于开仓阈值，有利润空间）
- FR-015: 系统必须支持可配置的盈利目标率，默认值为0.02%（接受微薄盈利）

### 关键实体

- 仓位平衡状态（PositionBalance）：表示两个交易所之间仓位的平衡程度
  - extended_total_qty: Extended交易所总仓位（带符号）
  - lighter_total_qty: Lighter交易所总仓位（带符号）
  - diff_qty: 仓位差异数量（使用绝对值相减）
  - diff_rate: 差异率（diff_qty / 总暴露度）
  - is_imbalanced: 是否失衡（diff_rate超过阈值）
  - warning_level: 警告级别（OK/WARN/CRITICAL）

- 价差记录（SpreadRecord）：记录市场价差的实时数据
  - timestamp: 时间戳
  - extended_bid/ask: Extended交易所买卖价
  - lighter_bid/ask: Lighter交易所买卖价
  - long_spread/long_spread_rate: 做多价差（绝对值和比率）
  - short_spread/short_spread_rate: 做空价差（绝对值和比率）
  - total_cost_rate: 总手续费成本率

- 交易配置（SpreadArbConfig）：可配置的交易参数
  - min_spread_rate: 最小开仓价差率（默认0.06%）
  - profit_target_rate: 目标盈利率（默认0.02%）
  - min_close_profit_rate: 最小平仓利润率（默认0.03%）
  - latency_buffer: 延迟缓冲（默认0.01%）
