# Feature Specification: 统一持仓监控显示并增加平仓收益实时计算

**Feature Branch**: `005-unify-position-monitor`
**Created**: 2026-01-09
**Status**: Draft
**Input**: User description: "合并持仓监控显示并增加平仓收益实时计算"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 统一持仓监控显示 (Priority: P1)

交易员在查看持仓监控信息时，希望看到合并后的单一仓位信息，而不是重复显示多个相同方向的仓位。这样可以更清晰、更简洁地了解当前整体持仓状态。

**Why this priority**: 这是用户体验的核心需求，当前显示多个重复的仓位信息导致界面混乱，影响交易员快速判断持仓状态。

**Independent Test**: 可以通过启动套利机器人并开启多个同向仓位，验证监控输出是否只显示一个合并的仓位信息来独立测试。

**Acceptance Scenarios**:

1. **Given** 交易员有3个做多仓位在同一交易所，**When** 查看持仓监控输出，**Then** 只显示一个合并后的持仓信息
2. **Given** 交易员有多个做空仓位在同一交易所，**When** 查看持仓监控输出，**Then** 只显示一个合并后的持仓信息
3. **Given** 交易员有做多和做空仓位，**When** 查看持仓监控输出，**Then** 分别显示合并后的做多和做空持仓信息

---

### User Story 2 - 实时显示平仓后收益 (Priority: P1)

交易员在查看持仓监控时，希望看到如果立即平仓，扣除所有手续费后实际能获得多少收益。这样可以做出更明智的平仓决策。

**Why this priority**: 这是交易决策的关键信息，没有准确的平仓收益计算，交易员无法判断当前是否应该平仓。

**Independent Test**: 可以通过开启持仓并查看监控输出，验证"平仓后的收益"字段是否正确计算并显示来独立测试。

**Acceptance Scenarios**:

1. **Given** 交易员持有做多仓位，**When** 查看持仓监控输出，**Then** 显示准确的平仓后收益（包含价差收益和手续费）
2. **Given** 交易员持有做空仓位，**When** 查看持仓监控输出，**Then** 显示准确的平仓后收益（包含价差收益和手续费）
3. **Given** 当前价格为亏损状态，**When** 查看持仓监控输出，**Then** 平仓后收益显示负数（亏损金额）

---

### User Story 3 - 清晰的持仓信息展示 (Priority: P2)

交易员希望持仓监控信息清晰易读，包含所有关键信息（持仓时间、剩余时间、仓位详情、当前价格、未实现盈亏、距离盈利目标差距、平仓后收益）。

**Why this priority**: 信息展示的清晰度直接影响交易员的决策效率，但优先级略低于前两个功能需求。

**Independent Test**: 可以通过查看监控输出的格式和内容，验证是否包含所有必要信息且格式清晰来独立测试。

**Acceptance Scenarios**:

1. **Given** 交易员查看持仓监控，**When** 查看输出信息，**Then** 包含持仓时间、剩余时间、Extended仓位、Lighter仓位、当前价格、未实现盈亏、距离盈利目标、平仓后收益
2. **Given** 监控信息输出，**When** 交易员阅读，**Then** 信息格式清晰、层次分明、易于理解

---

### Edge Cases

- 当持仓数量为0时，如何显示监控信息？
- 当交易所API返回的价格数据异常时，如何处理平仓收益计算？
- 当部分仓位成交失败时（如Extended成交但Lighter失败），如何计算和显示收益？
- 当手续费信息获取失败时，如何显示平仓后收益？

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须将同一交易所的多个同向仓位合并显示为一个持仓信息
- **FR-002**: 系统必须实时计算并显示"平仓后的收益"字段
- **FR-003**: 平仓后收益计算必须包含交易所持仓的价差收益
- **FR-004**: 平仓后收益计算必须扣除所有相关手续费（开仓手续费和平仓手续费）
- **FR-005**: 系统必须在持仓监控输出中包含所有关键信息：持仓时间、剩余时间、合并后的仓位详情、当前价格、未实现盈亏、距离盈利目标差距、平仓后收益
- **FR-006**: 当做多和做空仓位同时存在时，系统必须分别显示合并后的做多和做空持仓信息
- **FR-007**: 系统必须使用对手价进行平仓收益计算，以模拟真实的市价平仓结果
- **FR-008**: 当价格数据异常时，系统必须显示错误提示而不是错误的收益值
- **FR-009**: 系统必须以清晰易读的格式输出持仓监控信息

### Key Entities

- **统一持仓**: 合并后的同一交易所同向仓位，包含总数量、平均开仓价格、开仓时间范围
- **平仓收益**: 实时计算的如果立即平仓扣除手续费后的净收益
- **价差收益**: 两个交易所之间的价格差异产生的收益
- **手续费成本**: 开仓和平仓时产生的所有交易费用总和

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 持仓监控输出只显示一个合并的仓位信息（当存在多个同向仓位时）
- **SC-002**: 平仓后收益计算准确率达到100%（与实际平仓结果一致）
- **SC-003**: 持仓监控信息在1秒内完成计算和显示
- **SC-004**: 用户能够在监控输出中清晰识别所有关键信息（持仓时间、剩余时间、仓位详情、当前价格、未实现盈亏、距离盈利目标、平仓后收益）

## Assumptions

- 假设交易所提供的对手价数据准确且实时
- 假设手续费率是固定的或可以通过API获取
- 假设同一交易所的多个同向仓位可以安全地合并显示
- 假设用户使用简体中文阅读监控信息
- 假设持仓监控输出频率为每秒一次（与当前实现保持一致）
