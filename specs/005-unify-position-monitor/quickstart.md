# Quickstart: 统一持仓监控显示并增加平仓收益实时计算

**Feature**: 005-unify-position-monitor
**Date**: 2026-01-09

## 功能概述

本功能优化了价差套利机器人的持仓监控输出，主要改进：

1. **合并显示**：将多个同向仓位合并为一个统一仓位视图
2. **实时收益**：计算并显示平仓后的净收益（扣除手续费）
3. **清晰界面**：使用简体中文，格式清晰易读

## 快速开始

### 1. 使用新功能

启动套利机器人后，持仓监控会自动使用新的统一显示格式：

```bash
python spread/bot.py --ticker ETH --size 35 --max-pairs 3
```

输出示例：

### 2. 配置手续费率

在 `spread/config.py` 中配置手续费率（已预设默认值）：

```python
@dataclass
class SpreadArbConfig:
    # 现有配置...

    # 新增：手续费率配置
    extended_fee_rate: Decimal = Decimal('0.000225')  # 0.0225%
    lighter_fee_rate: Decimal = Decimal('0.0')         # 0%
```

### 3. 理解输出字段

| 字段 | 说明 |
|------|------|
| 总数量 | 该方向所有仓位的数量总和 |
| Extended平均价格 | 按数量加权的平均开仓价格 |
| Lighter平均价格 | 按数量加权的平均开仓价格 |
| 持仓时间 | 最早到最晚开仓的时间范围 |
| 剩余时间 | 距离强制平仓的剩余时间 |
| 当前价格 | Extended和Lighter的实时价格 |
| 未实现盈亏 | 价差收益（不含手续费） |
| 距离盈利目标 | 距离目标利润的差距 |
| **平仓后收益** | **扣除所有手续费后的净收益** |

## 故障排除

### 问题1：平仓后收益显示为None

**原因**：订单簿数据为空或价格无效

**解决**：检查WebSocket连接状态，确认订单簿数据正常接收

### 问题2：手续费计算不准确

**原因**：手续费率配置错误

**解决**：在 `config.py` 中检查 `extended_fee_rate` 和 `lighter_fee_rate` 配置

### 问题3：持仓合并不符合预期

**原因**：持仓方向判断错误

**解决**：检查 `SpreadPair.extended_side` 字段，确保 'buy'=做多，'sell'=做空
