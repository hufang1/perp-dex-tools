# Quickstart Guide: 优化持仓监控输出

**Feature**: 001-optimize-monitor
**Date**: 2026-01-09

## Overview

本功能优化了价差套利机器人的持仓监控输出，将多个分散的日志整合为单一输出，并新增了"当前已实现收益"字段，帮助交易员更好地了解整体持仓状况。

## Key Features

### 1. 整合输出
- ✅ 所有持仓信息集中在一条日志中
- ✅ 单一时间戳，便于查看和分析
- ✅ 减少日志噪音，提高可读性

### 2. 当前已实现收益（新增）
- **含义**: 如果立即使用对手价平仓的理论收益
- **用途**: 帮助交易员做出更明智的平仓决策
- **计算**:
  - 做多: Extended用bid平仓，Lighter用ask平仓
  - 做空: Extended用ask平仓，Lighter用bid平仓

### 3. 总览摘要
- 总持仓数量
- 总未实现盈亏
- 快速了解整体状况

## Understanding the Output

### 输出字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 持仓 #ID | 持仓唯一标识 | `持仓 #1` |
| (做多/做空) | 持仓方向 | `(做多)` |
| 持仓时间 | 从开仓到现在的时长 | `89秒` |
| 剩余时间 | 距离强制平仓的时间 | `1711秒` |
| Extended仓位 | Extended交易所仓位 | `0.0100 @ $3114.70` |
| 当前价格 | Extended当前价格 | `$3115.50` |
| Lighter仓位 | Lighter交易所仓位 | `0.0100 @ $3086.27` |
| 当前价格 | Lighter当前价格 | `$3117.73` |
| **当前已实现收益** | 立即平仓的理论收益 | `$-0.31` |
| 未实现盈亏 | 基于中间价的盈亏 | `$-0.31` |
| 距离盈利目标 | 达到盈利目标的差距 | `$0.32` |

### 已实现收益 vs 未实现盈亏

**当前已实现收益**（新增）:
- 使用**对手价**（bid/ask）计算
- 反映立即平仓的实际收益
- 更准确，但可能包含买卖价差成本
- 用途: 做平仓决策时参考

**未实现盈亏**（现有）:
- 使用**中间价**计算
- 反映理论盈亏
- 用途: 监控持仓趋势

## Troubleshooting

### Q: 为什么当前已实现收益显示为N/A？

**A**: 订单簿数据缺失或WebSocket连接中断。检查：
- WebSocket连接状态
- 交易所API是否正常
- 网络连接是否稳定

### Q: 当前已实现收益与未实现盈亏为什么不同？

**A**: 正常现象，两者计算方式不同：
- 已实现收益: 使用对手价（bid/ask），包含买卖价差
- 未实现盈亏: 使用中间价，理论值

### Q: 输出格式会改变交易逻辑吗？

**A**: 不会。本功能仅修改日志输出格式，不影响任何交易决策或执行逻辑。

### Q: 如何验证已实现收益计算的准确性？

**A**: 手动计算验证：
```
做多持仓:
  Extended盈亏 = (bid - 开仓价) × 数量
  Lighter盈亏 = (开仓价 - ask) × 数量
  总收益 = Extended盈亏 + Lighter盈亏
```
